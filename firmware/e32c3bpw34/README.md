Current Prototype Wiring

The current prototype uses a 1.65 V reference generated by a 10 kΩ / 10 kΩ voltage divider from the 3.3 V supply. The OPA380 is powered from 3.3 V.

ESP32 3.3 V ───── OPA380 pin 7
ESP32 GND ─────── OPA380 pin 4


ESP32 3.3 V
     │
   10 kΩ
     │
     ├──────── OPA380 pin 3
     │
   10 kΩ
     │
ESP32 GND


OPA380 pin 6 ──── output

| OPA380 pin | Connect to             | Purpose                 |
| ---------: | ---------------------- | ----------------------- |
|      **1** | NC                     | No connection           |
|      **2** | BPW34 + 1 MΩ resistor  | Inverting TIA input     |
|      **3** | 1.65 V reference       | Non-inverting reference |
|      **4** | ESP32 GND              | V−                      |
|      **5** | NC                     | No connection           |
|      **6** | Output + 1 MΩ resistor | TIA output              |
|      **7** | ESP32 **3.3 V**        | V+                      |
|      **8** | NC                     | No connection           |


1 MΩ resistor is directly soldered between pins 2 and 6.

100 nF ceramic capacitor is directly soldered between pins 7 and 4.

The current prototype has demonstrated a strong BPW34 response:

Condition	OPA380 output
Dark	~1.7 V
Room light	~0.1 V
Strong LED	~0.01 V
